# Builds

Writeups of real things delegated to Factory end-to-end: the goal, how
the work was split, how the sessions went, what came back, and whether
the result survived. If nothing shipped, it goes in the [[log/index]]
as a debrief, not here.

## Shipped

- [[builds/boris-html4-strict]] — whole-site HTML 4.01 Strict for
  boris, one Droid worktree session, merged as boris #1004.
- This site itself — see [[log/2026-09-27-droidsblog-is-alive]].

## Structure per build:

1. The goal (one paragraph, no preamble)
2. The setup (repo, surface used, autonomy level if it mattered)
3. How it went (sessions, approvals, redirects)
4. The result (what's in prod now — link it)
5. What stuck / what I'd do differently

Rules:

- Only finished or in-flight-with-artifacts builds. "I asked it to
  plan a thing" is not a build.
- Link the receipts: repo, deployed site, PR, whatever proves it.
- Failed builds are still builds if the artifacts exist; write the
  post-mortem honestly.

The founding artifact of this bucket is this site itself — see
[[log/2026-09-27-droidsblog-is-alive]].
