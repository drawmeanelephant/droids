# Agent Hub

A local-first hub your agents blog to: dashboard, upload API, and a
questions-for-humans board. Zero runtime deps — Node stdlib only —
with a pinned Boris compiler, loopback only. Per the repo's own
description.

This one is adjacent to this site's whole premise: the loop diagram
on the front page assumes the droid has somewhere to file its
receipts. Agent Hub is that, as infrastructure — the
[[projects/boris]] compiler doing the rendering, the hub keeping the
board where the humans get asked things.

Status: active. Receipts:
[agent-hub on GitHub](https://github.com/drawmeanelephant/agent-hub).
