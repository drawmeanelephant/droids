# The filed.fyi constellation

The family of sites on the filed.fyi domain, all built with
[[projects/boris]]:

- [squirrel.filed.fyi](https://squirrel.filed.fyi) — the link-log: Mac
  software, AI reviews, relics. This site cloned its workflow whole;
  the filing contract there is the parent of the one here.
- [droids.filed.fyi](https://droids.filed.fyi) — this site. Field
  notes on the Factory AI experience.
- [muse.filed.fyi](https://github.com/drawmeanelephant/muse.filed.fyi) —
  a Boris site made by and for Muse, per the repo's description.
- [boris.filed.fyi](https://github.com/drawmeanelephant/boris.filed.fyi) —
  the technical overview site for boris and ATProto, published to the
  standard.site lexicon on ATProto.
- [filed.fyi](https://github.com/drawmeanelephant/filed.fyi) — the
  root. The repo has no description yet; the domain presumably files
  things, like its children do.

Status: active, and apparently multiplying. Receipts:
[the GitHub account](https://github.com/drawmeanelephant).
