# The oracle is a witness, not a pope

- Surface: repository and differential-corpus study
- Date: 2026-10-01
- Evidence: the source receipts below and
  `2026-10-01-empire-self-study.assets/04-k4o/oracle-corpus.md`
- Verdict: keep

## Where we are

I sent this card out to map an oracle for a planned Markdown backend.
The plan had already become furniture: CommonMark was merged in
[#18](https://github.com/drawmeanelephant/k4o/pull/18), and opt-in GFM
tables followed in [#20](https://github.com/drawmeanelephant/k4o/pull/20).
Textile still gets the front door; the other formats are
[explicit choices](https://github.com/drawmeanelephant/k4o/blob/59f88233589d2643ba5b4f380e3db70664bba2b3/README.md#L213-L249).
Sometimes the first useful finding is: don't build it twice.

## What's improved

The oracle is a pinned creature: Obsidian's npm `knap@0.6.0`, with its
dependency and integrity recorded in the
[lockfile](https://github.com/drawmeanelephant/k4o/blob/59f88233589d2643ba5b4f380e3db70664bba2b3/tools/differential/package-lock.json),
not whichever package wanders past `npx` today. The unchanged harness
passed 99 checks in the scratch build; 75 were byte-identical oracle
checks, not a promise about the whole language.
[Documented boundary](https://github.com/drawmeanelephant/k4o/blob/59f88233589d2643ba5b4f380e3db70664bba2b3/README.md#L366-L402);
executed evidence is in
`2026-10-01-empire-self-study.assets/04-k4o/evidence.json`.

Factory is in the record: the
[CommonMark](https://github.com/drawmeanelephant/k4o/commit/1a8761fb5d3166c8629d04542587aa6b78ee9771)
and
[GFM](https://github.com/drawmeanelephant/k4o/commit/31dc815375a4a3b1e6e405fe92884a7b21206422)
commits carry its co-author credit. That records collaboration, not
which model wore the hard hat.

## What's next

The extra 52 paired probes found useful nits: empty code grows visible
backticks, all-space code gains two spaces, a fence adds a terminal
newline, and a nested ordered-list child loses its parent when
numbering reaches ten. Actual inputs, outputs, and rendered HTML are
retained in
`2026-10-01-empire-self-study.assets/04-k4o/measured-cases.json`.
The scoped repairs are
[#21, code boundaries](https://github.com/drawmeanelephant/k4o/issues/21),
and
[#22, marker-width nesting](https://github.com/drawmeanelephant/k4o/issues/22).

A scalar `"1. numbered"` also becomes a nested list. Knap does that
one too, which is a reminder that an oracle is a witness, not a pope.
[#23](https://github.com/drawmeanelephant/k4o/issues/23) keeps that
regression in the structural lane rather than demanding byte parity.

The research implemented no backend repairs. It left an executable
corpus map, three filed follow-ups, and eight explicitly unexecuted
proposed cases. No GFM-aware renderer was tested; the npm tarball's
exact upstream source commit remains unestablished. Those limits are
recorded in the corpus map, not sanded away until everything looks
green.
