## Surviving evidenced concerns

1. **Reference provisioning still fails on transient network errors without a bounded clone retry.** The failed job demonstrates this; current [cache-miss block](https://github.com/drawmeanelephant/fart-app/blob/cc2cd4a6b4f07d14f439004db981db7a1055f807/.github/workflows/ci.yml#L201-L231) still has a single clone under `set -euo pipefail`. Recommend a small provisioning-hardening follow-up, not a product/session fix. Keep compilation and demo failures fatal; do not blindly retry the entire demo to manufacture green.
2. **Reference identity is computed but not enforced.** The key resolves mutable upstream main using `ls-remote`; the miss branch separately clones default HEAD and merely prints actual versus expected SHA. A branch advance between these calls can label the wrong build with the earlier SHA. Warm restores likewise lack an explicit expected-SHA/manifest assertion. This is source-proven missing validation, **not an observed wrong-binary incident**. Include exact-SHA checkout/validation in the same bootstrap hardening scope. [Key](https://github.com/drawmeanelephant/fart-app/blob/cc2cd4a6b4f07d14f439004db981db7a1055f807/.github/workflows/ci.yml#L179-L199), [clone and echo](https://github.com/drawmeanelephant/fart-app/blob/cc2cd4a6b4f07d14f439004db981db7a1055f807/.github/workflows/ci.yml#L201-L210), [demo records actual only](https://github.com/drawmeanelephant/fart-app/blob/cc2cd4a6b4f07d14f439004db981db7a1055f807/demo/run_demo.sh#L41-L45).
3. **Evidence upload can look like evidence of a demo that never ran.** `demo/evidence/` is already tracked in the repository. Attempt 1 uploaded 26 files despite skipping the demo. The upload step unconditionally packages that directory on failure. Preserve historical evidence, but segregate current-run evidence and provision logs/phase metadata so consumers can distinguish them. [Upload](https://github.com/drawmeanelephant/fart-app/blob/cc2cd4a6b4f07d14f439004db981db7a1055f807/.github/workflows/ci.yml#L236-L243), [committed evidence tree](https://github.com/drawmeanelephant/fart-app/tree/cc2cd4a6b4f07d14f439004db981db7a1055f807/demo/evidence), [failed log](https://github.com/drawmeanelephant/fart-app/actions/runs/36856588659/job/110351731710). This belongs in the same narrow diagnostics follow-up.

The key intentionally has no restore-prefix fallback. It includes upstream SHA and refpeer source hash but not runner architecture/image, recipe version, compiler or SDK. Explicit recipe/platform identity is reasonable preventive hardening; **no ABI mismatch was observed**. Do not invent a separate portability bug from that omission. [Cache policy](https://github.com/drawmeanelephant/fart-app/blob/cc2cd4a6b4f07d14f439004db981db7a1055f807/.github/workflows/ci.yml#L155-L158), [key](https://github.com/drawmeanelephant/fart-app/blob/cc2cd4a6b4f07d14f439004db981db7a1055f807/.github/workflows/ci.yml#L179-L199).
